Exam info

Get your laptop ready for the offline notebook exam, save a copy of everything you want with you, and practise with three complete mock exams. The official exam cover gives the rules for the sitting itself.

The exam at a glance

180 minuteson site, offline, in VS Code
Two parts50 points each
No AIthe exam cover sets the other rules
Two filesyour answer notebook and the blank PDF

The cheatsheet is allowed, as a copy saved on your laptop: the course site cannot be opened during the exam, so download the PDF below beforehand.

Get ready, in this order

  1. Save your offline copies while you have internet: the course ZIP, the lecture PDFs and the cheatsheet, all below.
  2. Install Python 3.14 and the course's packages with the one install line on the setup page, so your numbers match the materials.
  3. Run the setup check with Wi-Fi off. setup_check.ipynb is in the course ZIP: open the unzipped folder in VS Code and press Run All. It ends with ready, or a list of what to fix.
  4. Switch off AI and code completion in VS Code, as page 2 of the practicalities guide shows.
  5. Sit one mock exam in three uninterrupted hours on that laptop, then read its code solutions.
