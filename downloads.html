You do not need any of this to follow the course: the lectures run in your browser and the notebooks open in Colab with the data loading by itself. This page is for working offline, on your own machine, which is what you will do at the exam.

All the notebooks and data, in one file

Every exercise notebook, every case notebook and every data file, arranged so they work as soon as you unzip them, with the list of package versions the course was checked with. Always the current version.

↓ Download the course materials (ZIP) about 7.5 MB · unzip it anywhere

Unzip it, then in VS Code use File → Open Folder and pick the unzipped folder. Opening the folder rather than a single file is what makes data/prices.csv resolve. See the setup guide.

Running the notebooks locally

  1. Follow the setup guide once: Python 3.14, VS Code, the Python extension, and the course's packages, installed from a notebook cell with %pip install -r https://theill95.github.io/mlfin-2026/requirements.txt.
  2. Put the notebook and a data/ folder in the same place, exactly as in the ZIP.
  3. In VS Code, File → Open Folder and choose that folder. Not the file: the folder.
  4. Open the notebook, pick your Python when asked, and run the first cell.
If you skip the data files entirely, the notebooks still work: when they cannot find a local data/ folder they download what they need from this repository. You only need the CSVs if you want to work with no internet at all.

A note on the lectures

The interactive lectures are not in the ZIP. Their code cells run Python inside the browser, and that only works when the page is served over the web rather than opened from a file on your disk. It is a browser restriction, not a course one. So the slides are best used online, from the sessions page, where they always work and are always current.

For offline reading, every lecture is also a PDF with the result of every code cell: each session's table above has it, and the Exam info page has all thirteen in one place. Everything you actually write code in, the exercises and the case, is in the ZIP and works completely offline.
